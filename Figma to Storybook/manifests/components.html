# Portfolio design system

React components built from the Figma page **❖ Components**
([My-project](https://www.figma.com/design/bHRn6PCs8dDNpgPaYAnZ0p/My-project?node-id=1-57)).
Each component has the same properties and default content as in Figma. The real page content lives only in the app.

## Sections

- **Foundations**: colours, typography, spacing and radius. They're read straight from `src/tokens.css`, a 1:1 copy of the Figma variable collections and modes.
- **Primitives**: Button, Link button, Icon, Logo.
- **Layout**: Navigation, Footer.
- **Sections**: Hero, Project card, About, Picture, Skill, Skills.

Every component has a **Docs** page with its props (the Figma properties) and all its stories.

## Toolbar

- **Theme**: Figma mode of `colour semantics` (light / dark).
- **Frame**: Figma breakpoint mode (`>1280`, `>800`, `<800`) and frame width. Section stories set it themselves: Desktop 1280, Tablet 800, Mobile 375. The frame height hugs the content, like a Figma frame.

## Using a component

```tsx
import { DsRoot, ProjectCard } from './components';

<DsRoot>                              {/* sets the breakpoint mode from the window width */}
  <ProjectCard
    headlineText="My project"
    contentText="What I did and why."
    hasBg={false}
  >
    <img src={cover} alt="" />         {/* image slot, 16:9 */}
  </ProjectCard>
</DsRoot>
```

## When Figma changes

1. Variables: update `src/tokens.css` (same names as Figma, `/` → `-`). Foundations update by themselves.
2. Text styles: update `src/typography.css`.
3. Components: update the matching folder in `src/components/`. Props keep the Figma property names.
